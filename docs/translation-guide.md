# 翻译规范

- 面向中国大陆用户，使用简体中文和大陆动漫社区常用说法。
- 先理解 AniList 控件、状态或标签的页面语境，再确定译名，避免逐词直译。
- 作品标题优先采用稳定的大陆译名；多个译名并存时，以传播更广且含义准确的版本为主。
- 英文键必须与 AniList 页面原文精确一致，包括大小写、空格和标点。
- 标签基础译名放在 `src/data/tags/base.ts`；只有语境译名确实不同的条目才放入 `community.ts`。
- 人名、机构名和专有名词优先参考官方中文资料或可靠动画资料库，并在争议修改中附上来源。
- 成人或敏感标签使用中文社区可识别且含义准确的名称，不用含糊的自动翻译。
