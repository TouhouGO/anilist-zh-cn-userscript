# AniList 简体中文用户脚本设计

## 目标

为 `https://anilist.co/*` 提供 Tampermonkey/Violentmonkey 用户脚本，将 AniList 的界面控件、状态文案和作品标题显示为简体中文。

## 范围

覆盖全局导航、搜索、首页、动画/漫画详情、列表、用户页、通知、论坛、推荐、统计和所有设置子页，以及异步加载的弹窗、下拉菜单、Toast、分页、空状态和错误状态。作品标题按 AniList ID 替换为中文标题。

排除简介、评论正文、活动正文、论坛帖子、用户签名、用户名、角色名和制作人员姓名等用户或内容数据。

## 技术方案

- 独立 TypeScript 用户脚本，使用 Vite/esbuild 生成单文件发行版。
- `MutationObserver` 只扫描新增节点；路由层监听 History API 和 `popstate`。
- UI 词典按页面模块拆分，采用精确文本、上下文选择器和带参数模板三类规则。
- 所有替换保存原始值和脚本标记，保证重复渲染幂等，并避免翻译用户内容。
- 标题服务从 `soruly/anilist-chinese` JSON 数据按作品 ID 匹配；数据繁简转换使用 `opencc-js` 的繁转简转换器，并由人工覆盖表修正专名。
- 标题数据本地缓存 24 小时；网络失败时继续使用上一次缓存和内置最小快照。
- 诊断模式记录未匹配的疑似 UI 文案，但不上传页面内容。

## 运行与更新

脚本入口使用 `@match https://anilist.co/*`、版本元数据和更新地址。标题数据更新与脚本更新解耦；脚本启动先使用缓存，后台刷新数据。所有外部请求仅访问公开 JSON 数据源，失败不会阻塞页面。

## 验收标准

1. 主要页面和设置子页不出现已收录的英文 UI 文案。
2. AniList 无刷新路由、懒加载列表和弹窗出现后 500ms 内完成翻译。
3. 标题库命中作品显示简体中文；未命中作品保留原标题。
4. 简介、评论、活动正文、论坛正文和用户字段保持原文。
5. 重复 MutationObserver 触发不会产生重复节点、重复前缀或反复转换。
6. 无网络、数据源超时或数据格式错误时，页面仍可正常使用。
7. 单元测试覆盖规则匹配、模板变量、路由解析、缓存过期、标题优先级和排除区域；构建产物可直接安装到 Tampermonkey/Violentmonkey。
